## Summary

StoredCheckpoint wraps a Checkpoint with its attestation proof data and storage metadata for persistence in CF_CHECKPOINTS.

---

## Specification

```rust
use chia_bls::{PublicKey, Signature};
use chia_protocol::Bytes32;
use dig_block::{Checkpoint, SignerBitmap};
use serde::{Deserialize, Serialize};

/// A checkpoint with its attestation proof, stored in CF_CHECKPOINTS.
/// Keyed by epoch number (big-endian u64).
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct StoredCheckpoint {
    /// The checkpoint data (epoch, block hash, state root, etc.)
    pub checkpoint: Checkpoint,

    /// Bitmap indicating which signers contributed to the aggregate signature.
    pub signer_bitmap: SignerBitmap,

    /// BLS aggregate signature over the checkpoint.
    pub aggregate_signature: Signature,

    /// BLS aggregate public key of the signers.
    pub aggregate_pubkey: PublicKey,

    /// Attestation score (number of signers or weighted vote).
    pub score: u64,

    /// Index of the validator that submitted this checkpoint.
    pub submitter: u32,

    /// L1 block height where this checkpoint was anchored (if confirmed).
    pub l1_height: Option<u32>,

    /// L1 coin ID associated with the checkpoint submission (if confirmed).
    pub l1_coin_id: Option<Bytes32>,

    /// Unix timestamp when this checkpoint was stored locally.
    pub stored_at: u64,
}
```

### Serialization

StoredCheckpoint is serialized using bincode for storage in CF_CHECKPOINTS. The key is the epoch number encoded as an 8-byte big-endian u64 (for natural sort order by epoch).

### Field Details

| Field | Type | Description |
|-------|------|-------------|
| `checkpoint` | `Checkpoint` | Core checkpoint data from dig-block |
| `signer_bitmap` | `SignerBitmap` | Bit vector of contributing signers |
| `aggregate_signature` | `Signature` | BLS aggregate signature (96 bytes) |
| `aggregate_pubkey` | `PublicKey` | BLS aggregate public key (48 bytes) |
| `score` | `u64` | Attestation score |
| `submitter` | `u32` | Submitting validator index |
| `l1_height` | `Option<u32>` | L1 confirmation height |
| `l1_coin_id` | `Option<Bytes32>` | L1 coin ID for on-chain anchor |
| `stored_at` | `u64` | Local storage timestamp |

## Implementation Notes

- Define in `src/types/stored_checkpoint.rs`.
- `Checkpoint` and `SignerBitmap` come from the dig-block crate.
- `Signature` and `PublicKey` come from the chia-bls crate (`features = ["serde"]` in `Cargo.toml` for bincode).
- Serde `Serialize`/`Deserialize` are needed for bincode serialization.
- The `stored_at` field uses a Unix timestamp (seconds since epoch).
- **`Checkpoint` wire shape:** Defined in the `dig-block` crate (CKP-001: `epoch`, roots, counts, fees) — `StoredCheckpoint` embeds that type verbatim; do not duplicate fields in `dig-blockstore`.
