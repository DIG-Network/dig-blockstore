## Summary

The crate MUST define metadata key constants for CF_METADATA entries and RocksDB tuning default constants for store configuration.

---

## Specification

### Metadata Key Constants

```rust
/// Key for the current chain tip (ChainTip 40-byte encoding).
pub const META_TIP: &str = "tip";

/// Key for the genesis block hash (32 bytes).
pub const META_GENESIS_HASH: &str = "genesis_hash";

/// Key for the minimum retained block height (8 bytes little-endian u64).
pub const META_MIN_HEIGHT: &str = "min_height";

/// Key for the database schema version (8 bytes little-endian u64).
pub const META_SCHEMA_VERSION: &str = "schema_version";

/// Key for the trained zstd compression dictionary.
pub const META_ZSTD_DICT: &str = "zstd_dict";

/// Current schema version number.
pub const SCHEMA_VERSION: u64 = 1;
```

### RocksDB Tuning Defaults

```rust
/// Default RocksDB write buffer size: 64 MB.
pub const DEFAULT_WRITE_BUFFER_SIZE: usize = 64 * 1024 * 1024; // 67_108_864

/// Default RocksDB block cache size: 128 MB.
pub const DEFAULT_BLOCK_CACHE_SIZE: usize = 128 * 1024 * 1024; // 134_217_728

/// Default maximum number of open files for RocksDB.
pub const DEFAULT_MAX_OPEN_FILES: i32 = 1000;

/// Default bloom filter bits per key.
pub const DEFAULT_BLOOM_BITS_PER_KEY: i32 = 10;

/// Default in-memory block cache capacity (number of blocks).
pub const DEFAULT_BLOCK_CACHE_CAPACITY: usize = 1000;

/// Default in-memory header cache capacity (number of headers).
pub const DEFAULT_HEADER_CACHE_CAPACITY: usize = 2000;

/// Default zstd compression level.
pub const ZSTD_COMPRESSION_LEVEL: i32 = 3;
```

## Implementation Notes

- Define in `src/constants.rs` alongside the CF_* constants from TYP-001.
- Meta key constants are re-exported from the crate root per STR-003.
- DEFAULT_* constants are used by `BlockStoreConfig::default()` (TYP-008).
- SCHEMA_VERSION is written to CF_METADATA on first open and checked on subsequent opens.
