## Summary

StorageStats provides a snapshot of the block store's contents and dimensions, used for monitoring, diagnostics, and API responses.

---

## Specification

```rust
/// Statistics about the contents and size of the block store.
///
/// Returned by `BlockStore::stats()` for monitoring and diagnostics.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct StorageStats {
    /// Total number of blocks stored (all chains, including forks).
    pub block_count: u64,

    /// Number of blocks in the canonical chain.
    pub canonical_block_count: u64,

    /// Total number of headers stored.
    pub header_count: u64,

    /// Total number of checkpoints stored.
    pub checkpoint_count: u64,

    /// Total number of attested blocks stored.
    pub attested_count: u64,

    /// Height of the current chain tip, or None if the store is empty.
    pub tip_height: Option<u64>,

    /// Minimum retained block height, or None if no pruning has occurred.
    pub min_height: Option<u64>,

    /// Total approximate size on disk in bytes.
    pub total_size_bytes: u64,
}
```

## Implementation Notes

- Define in `src/types/storage_stats.rs`.
- This is a pure data struct with no methods beyond what `Default` provides.
- `BlockStore::stats()` (defined in the block_storage domain) populates this struct.
- `total_size_bytes` can be estimated via RocksDB's `GetAggregatedIntProperty("rocksdb.estimate-live-data-size")`.
