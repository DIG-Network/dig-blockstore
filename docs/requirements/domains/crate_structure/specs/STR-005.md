## Summary

Test infrastructure MUST provide reusable helpers for creating temporary RocksDB stores, test blocks with deterministic hashes, small-cache test configs, and linked block chains.

---

## Specification

### Temporary RocksDB Directory Helper

```rust
/// Creates a temporary directory for a RocksDB store that is
/// automatically cleaned up when the returned guard is dropped.
pub fn temp_blockstore_dir() -> (TempDir, PathBuf) {
    let dir = tempfile::tempdir().unwrap();
    let path = dir.path().to_path_buf();
    (dir, path)
}
```

### Chain Builder

```rust
/// Builds a chain of `n` linked blocks starting from genesis.
/// Returns the blocks in order [genesis, block_1, ..., block_{n-1}].
/// Each block's parent_hash points to the previous block's hash.
pub fn build_chain(n: usize) -> Vec<L2Block> {
    let genesis_hash = Bytes32::default(); // or zero hash
    let mut blocks = Vec::with_capacity(n);
    let mut parent = genesis_hash;
    for height in 0..n {
        let block = test_block(height as u64, parent);
        parent = block.hash();  // computed deterministically
        blocks.push(block);
    }
    blocks
}
```

## Acceptance Criteria

- [ ] `temp_blockstore_dir()` creates a directory that exists on disk
- [ ] `temp_blockstore_dir()` directory is cleaned up when guard is dropped
- [ ] `test_block()` returns a valid L2Block at the specified height
- [ ] `test_block()` uses the provided parent_hash
- [ ] `test_block()` is deterministic (same inputs produce identical blocks)
- [ ] `test_header()` returns a valid L2BlockHeader matching `test_block()` output
- [ ] `test_config()` returns a config with small cache capacities
- [ ] `test_config()` disables blob DB and compression for test simplicity
- [ ] `build_chain(n)` returns exactly `n` blocks
- [ ] `build_chain(n)` has correct parent-child hash linking
- [ ] `build_chain(1)` returns just a genesis block with default parent hash

---

## Implementation Notes

- Place helpers in a `tests/common/mod.rs` or `src/test_helpers.rs` (cfg(test)) module.
- Deterministic hashing requires that all fields fed into the hash are fixed given height and parent_hash. Use simple patterns like zeroed fields or height-derived values.
- The `tempfile` crate handles automatic cleanup via `TempDir`'s `Drop` impl.
- These helpers will be used extensively by every other domain's test suite.
